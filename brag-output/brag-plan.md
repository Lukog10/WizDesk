# Brag Plan: WizDesk

## What is this app?
WizDesk is an autonomous, local-first desktop companion for Windows that tracks focused active windows every 5 seconds, features an interactive on-screen mascot, manages tasks with live stopwatch timers, and auto-syncs work notes directly into your personal Obsidian Markdown vault.

## The angle
The authentic developer story: You code for 3 to 4 hours straight in deep flow, but when you stop, you have no idea what got finished and what was left behind. Enter Wiz: an expressive desktop companion that quietly remembers your flow, keeps your tasks organized without manual timer friction, and stores everything 100% locally with zero telemetry.

## Hook (first 2-3 seconds)
A focused dark developer desktop with code editor and terminal. A continuous flow badge reads `3h 42m`. Typing halts, and two sharp question cards appear: "What did I actually finish?" and "What is still left unfinished?"

## Key moments (the middle)
- The Mascot Reveal: Wiz bounces onto the screen, his pupils dynamically tracking the mouse cursor as it circles and boops him.
- Autonomous Tracking: Wiz docks into the corner, tracking window switches quietly while the minimal floating Quick Bar Island docks at the desktop edge without manual stopwatches or hotkeys.
- The Full Workspace: A click on the island smoothly unfolds the 920x680 QuickEntry workspace with live ticking stopwatch timers, color tag badges, and project distribution Donut charts.
- Local-First Security & Obsidian: AES-256-GCM encryption badge beside an auto-syncing Obsidian Markdown daily note.

## Outro / punchline
A task is checked off, Wiz erupts with colorful confetti particles in celebration, and the official WizDesk logo settles with: "Focus in flow. Wiz remembers the rest."

## User flow worth showing
Code for hours -> questions arise -> meet Wiz on desktop -> watch active window focus auto-logged -> click island to view tasks with live stopwatches -> check off task -> Wiz celebrates -> clean Obsidian Markdown log created.
