## 3. Phased Execution Tasks

### Phase 1: Curated Vector Icons and Tags Storage Engine
- [ ] Create `assets/icons/tags/` with clean vector SVGs:
  - Technical: `code.svg`, `terminal.svg`, `bug.svg`, `git.svg`, `database.svg`, `server.svg`, `api.svg`, `cpu.svg`.
  - Design: `palette.svg`, `pen.svg`, `layout.svg`, `sparkle.svg`, `camera.svg`, `image.svg`.
  - Organization: `target.svg`, `compass.svg`, `flag.svg`, `star.svg`, `bookmark.svg`, `folder.svg`, `briefcase.svg`.
  - Research: `book.svg`, `search.svg`, `clipboard.svg`, `file-text.svg`, `link.svg`, `lightbulb.svg`.
  - General: `tag.svg`, `stopwatch.svg`.
- [ ] In `wiz/storage/db.py`, add tables:
  - `tags` (`id`, `name`, `icon`, `color`, `created_at`).
  - `task_tags` (`task_id`, `tag_id`).
  - `note_tags` (`note_id`, `tag_id`).
  - Migration logic for existing databases.
- [ ] In `wiz/storage/models.py`, define `TagRecord` and add `tags: List[TagRecord]` to `TaskRecord` and `NoteRecord`.
- [ ] In `wiz/storage/repository.py`, implement tag CRUD methods:
  - `create_tag(name, icon, color) -> TagRecord`.
  - `get_all_tags() -> List[TagRecord]`.
  - `delete_tag(tag_id) -> bool`.
  - `add_task_tag(task_id, tag_id)` / `remove_task_tag(task_id, tag_id)`.
  - `add_note_tag(note_id, tag_id)` / `remove_note_tag(note_id, tag_id)`.
- [ ] Add unit test suite in `tests/test_tags.py` and verify with pytest.

### Phase 3: Active Task Stopwatch and Duration Tracking
- [ ] In `wiz/storage/db.py`, add columns:
  - `duration_seconds INTEGER DEFAULT 0` on `tasks` and `subtasks`.
  - `timer_started_at TEXT DEFAULT NULL` on `tasks` and `subtasks`.
- [ ] Update `StorageRepository`:
  - `start_task_stopwatch(task_id)`: sets `timer_started_at = now()`, `status = in_progress`.
  - `pause_task_stopwatch(task_id)`: computes session delta, increments `duration_seconds`, clears `timer_started_at`.
  - `complete_task_stopwatch(task_id)`: flushes session delta, clears `timer_started_at`, marks `status = done`.
  - `flush_all_running_stopwatches()`: safely commits all active running timers to database on app exit.
- [ ] Implement `TaskStopwatchWidget` in `TaskRowWidget`:
  - Interactive stopwatch icon button + live elapsed time text.
  - QTimer interval 1000ms updating active tasks.
  - Support start, pause, and done transitions.
  - Displays completed duration badge (e.g. `24m` or `1h 15m`).
- [ ] Add app shutdown hook in `MainWindow` / `MascotWidget` / `WorkspaceDialog` to invoke `flush_all_running_stopwatches()`.
- [ ] Add unit test suite in `tests/test_stopwatch.py` and verify with pytest.

### Phase 4: Permanent Long Notes Engine and Workspace Editor
- [ ] In `wiz/storage/db.py`, migrate `notes` table with `title`, `updated_at`, `is_pinned`.
- [ ] Update `StorageRepository` with note methods:
  - `create_permanent_note(title, content, project_tag, tag_ids) -> NoteRecord`.
  - `update_permanent_note(note_id, title, content, project_tag, tag_ids) -> bool`.
  - `delete_permanent_note(note_id) -> bool`.
  - `get_permanent_notes() -> List[NoteRecord]`.
- [ ] Redesign Notes section in `wiz/ui/popup_dialog.py` / `wiz/ui/workspace_dialog.py`:
  - Top create bar: Title input + Project/Tag selectors + Create button.
  - Notes card list showing Title, snippet, project badge, tag pills, updated date.
  - Detail document editor with title, project/tag controls, and full multi-line Markdown text editor with debounced auto-save.
  - Obsidian vault sync writer exporting structured `.md` files into `<Vault>/WizNotes/`.
- [ ] Add unit test suite in `tests/test_notes.py` and verify with pytest.
